# Sydney Table Tennis Club (STTC) Website

Official website for Sydney Table Tennis Center, live at [sttc-website.vercel.app](https://sttc-website.vercel.app).

## Overview

A multi-page site for STTC covering club information, coaching programs, table hire bookings, a weekend social tournament series (STTC Legends), the weekly session timetable, and contact details.

## Pages

- **Home** — club overview and highlights
- **About** — club information
- **Group Coaching** / **Private Coaching** — structured coaching programs for all levels
- **Table Hire** — hourly table bookings for casual play or practice
- **STTC Legends** — weekly social tournament
- **Weekly Timetable** — session schedule
- **Contact Us**

## Tech Stack

Next.js, TypeScript, Tailwind CSS, deployed on Vercel.
